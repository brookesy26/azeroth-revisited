# Accessibility evidence register

This register covers all 86 current WCAG 2.2 success criteria at A, AA and AAA. Criterion 4.1.1 is obsolete in WCAG 2.2 and is excluded. The number 86 is the complete standard inventory, not a claim that every criterion applies or passes.

Status meanings: **pending** needs criterion-specific evidence; **tested** requires an actual recorded result and scope; **not applicable** identifies an absent feature in the current implementation and needs reassessment if that feature is added. No criterion is marked tested merely because a component was designed accessibly. This register does not assert whole-site AA or AAA conformance.

Reference: [W3C WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/). Manual screen-reader testing has not been performed. Automated scans are complementary evidence and cannot resolve all rows. The scope includes all exported routes, search, mobile navigation and the talent calculator. Review the complete interaction, not only its initial screen.

Last register update: 6 October 2026. Machine-readable equivalent: `accessibility-register.json`.
